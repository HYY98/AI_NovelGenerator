# 业务规则与红线

本文把“代码已实现”“当前风险”和“建议红线”分开，避免将建议误读为系统已经提供的安全能力。

## 1. 已确认的业务规则

### 1.1 AI 生成是候选流程

章节和设定卡的 AI 接口用于生成候选结果。候选不会自动覆盖正式章节正文或正式卡片；生成请求、输入快照、结果和采纳状态会写入 `generation_records`。正式内容必须经过用户或业务流程确认。

小说创建工作流 `create_novel_by_ai` 位于 [`backend/api/llm_routers/create_novel_router.py`](../backend/api/llm_routers/create_novel_router.py)，包含多个结构化步骤。步骤 Provider 和超时由工作流配置解析。

### 1.2 章节上下文有可见性边界

章节生成应使用当前章节可见的上下文，未来章节或尚未发生的事实不能被当作当前已知事实。实现细节集中在 `backend/services/llm/chapter_context_service.py` 及相关章节服务中。

### 1.3 章节状态和定稿

章节状态使用 `draft`、`editing`、`finalized` 等值。已定稿章节重新打开时进入 `editing`，不能直接回到 `draft`。定稿流程由审校和确认提交组成，相关实现位于：

- [`backend/services/novel/chapter_link_validator.py`](../backend/services/novel/chapter_link_validator.py)
- [`backend/services/novel/chapter_finalize_service.py`](../backend/services/novel/chapter_finalize_service.py)

定稿服务记录确认的角色事件，但不会在定稿过程中自动改写角色档案；档案更新应有明确的后续操作。

### 1.4 关联必须属于当前小说

章节关联的角色、地点、物品和规则卡需要经过类型、小说归属和删除状态检查。跨小说引用不应被当作有效上下文。

## 2. 配置与 Provider 规则

- Provider 配置由 YAML 文件管理，运行时会合并默认配置和本地配置。
- `NOVEL_GENERATOR_MONGODB_URL` 与 `NOVEL_GENERATOR_MONGO_DATABASE_NAME` 可作为进程级覆盖，不会回写配置文件。
- API 密钥只能放在本地私有配置或安全的运行环境中；文档、提交记录和日志示例只能使用占位符。
- CORS 只控制浏览器跨源策略，不是用户鉴权，也不是管理接口保护。

## 3. 当前风险与未实现边界

以下不是安全保证，而是需要在部署和后续开发中重点处理的边界：

1. 未确认项目具备完整登录、JWT、RBAC 或多租户权限体系。
2. 配置读写和 Provider 测试接口涉及敏感信息，公开部署前必须确认鉴权、网络边界和日志脱敏。
3. MongoDB 事务在不支持时会降级为顺序写入；部分批量写入有补偿逻辑，但不等于全量原子回滚。
4. 业务 ID 与 MongoDB `_id` 可能同时存在，接口转换时必须明确类型，不能靠字符串相等代替归属校验。
5. 软删除、关系停用和故事事件确认是不同概念，不能互相替代。

## 4. 建议红线

### 数据安全

- 不提交 `backend/config/config.yaml` 中的真实 API 密钥、密码、MongoDB URI 或生产地址。
- 不在日志、错误响应和文档中输出完整请求、Prompt、用户原文或 Provider 密钥。
- 生产数据库执行删除、重建索引或迁移前必须备份，并记录操作者、时间和影响范围。

### 业务一致性

- 不绕过章节归属、卡片类型和软删除校验写入关联字段。
- 不把 AI 候选直接当作用户确认后的正式内容。
- 不把未来章节内容注入当前章节上下文。
- 不复用已软删除对象的业务 ID，除非经过明确的数据迁移设计。

### 运维安全

- 不直接将后端或配置接口暴露到公网；部署前必须增加认证、网络隔离和最小权限。
- 不在不了解事务模式的情况下宣称跨集合操作可自动回滚。
- 清库、重建索引、恢复备份等破坏性操作必须人工确认，不能作为普通启动步骤。

## 5. 破坏性操作提示

`backend/db/indexes.py`、事务和仓储可能包含初始化、迁移或补偿行为。任何清理数据库、删除小说、重建集合或恢复备份的操作，都应先阅读对应代码并在隔离副本上演练。本次文档不提供清库命令，也未执行任何破坏性操作。

更多模型边界见：[数据模型](./03-数据模型.md)；运行防护见：[运行与部署](./05-运行与部署.md)。
